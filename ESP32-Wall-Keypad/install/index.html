Firmware installer

ESP32-Wall-Keypad

Flash firmware to your wall keypad directly from this browser tab — no IDE, no drivers, no command line. Works over USB from Chrome or Edge.

  1. Plug in the keypad's ESP32 board via USB.
  2. Click Install below and pick the matching serial port when prompted.
  3. Wait for the flash to finish — don't unplug or close the tab.
  4. Connect it to Wi‑Fi using the on‑screen setup once it reboots.
Your browser can't do this. Open this page in Chrome or Edge on a desktop computer — Web Serial isn't available in Firefox, Safari, or on iOS. This page needs to be served over HTTPS to flash devices — reload it from the GitHub Pages URL rather than a local file. Needs Web Serial — Chrome or Edge, desktop only.
